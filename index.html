How I work

Release gates written first

GEDA ERP ships in phases, each with pass criteria set before the work starts, such as “no duplicate inventory decrements” and “company isolation tests pass”.

Tests around the risky paths

The 674 tests in GEDA ERP cover areas like tenant isolation and document flows, where a bug means wrong books.

Security as a deliverable

Recovery planned in advance

GEDA ERP has a written backup and disaster recovery policy, with targets of 15 minutes of maximum data loss and 2 hours to restore service.
